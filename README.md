# Calculus Simulator

A standalone calculus learning website for solving integration and differentiation problems in the browser.

## What It Includes

- Integration solver with indefinite and definite modes
- Differentiation solver with derivative order controls
- Step-by-step solution output
- Graph visualization with Chart.js
- Built-in formula reference sheet
- Fully static frontend, ready for Vercel

## Project Files

```text
calculus-simulator/
├── index.html
├── theme.css
├── README.md
└── .gitignore
```

## Run Locally

Open `index.html` in a browser, or serve the folder with any static server.

```bash
npx serve .
```

## Deployment

This project is a static site. Deploy the repository root on Vercel.
