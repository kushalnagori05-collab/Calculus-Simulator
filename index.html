      About Calculus Simulator

      Calculus Simulator is a free, educational offline tool designed to help students learn and practice integration and differentiation. Enter any expression, get step-by-step solutions, and visualize the results on interactive graphs.

      How to Use

      1. 1Navigate to Integration or Differentiation.
      2. 2Type a math expression using standard notation: x^2, sin(x).
      3. 3Click Solve.

      Technologies Used

      Single HTML File

      Runs entirely offline, no server needed.

      Nerdamer

      Symbolic math engine.

      Chart.js

      Graph visualization library.

      Local Storage

      Database for calculation history.
